# El Campesino - Plataforma Web y Control de Inventario

Proyecto Integrador para la tienda "El Campesino" (Seminario Integrador / Ingeniería de Software II).

## Descripción
Aplicación web orientada a:
- Gestión de inventario con control de lotes y fechas de vencimiento (carnes, pollos, abarrotes).
- Catálogo de productos y gestión de pedidos a domicilio en tiempo real.
- Panel de asignación y despacho para repartidores.
- Módulo de proveedores, compras y trazabilidad de movimientos (Kardex).
